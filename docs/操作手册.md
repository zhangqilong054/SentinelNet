## 1. 系统概述

SentinelNet 哨兵网络是一个基于 Python 的实时网络入侵检测平台，集成了以下核心能力：

- **流量采集**：基于 Scapy/Npcap 的实时抓包，支持基础特征和增强特征提取
- **特征提取**：18 维网络流量特征，包括流级、TCP 行为、端口、时间、加密流量特征
- **双引擎检测**：规则检测（实时）+ ML 检测（周期聚合），三级告警（高危/中危/低危）
- **模型训练**：支持 RF/XGBoost/LightGBM/MLP/LR 五种算法，含交叉验证和算法对比
- **Web 监控**：Flask 实时仪表盘，含 QPS 趋势图、告警日志、攻击类型饼图
- **攻击模拟**：SYN Flood/端口扫描/UDP Flood 模拟，支持 pcap 文件生成

### 系统架构

```
┌─────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────────┐
│  流量采集    │───▶│  特征提取     │───▶│  双引擎检测   │───▶│  Web 监控面板     │
│  Scapy/Npcap│    │  18 维特征    │    │  规则 + ML    │    │  Flask 实时仪表盘 │
│  TLS 解析   │    │  JA3 指纹     │    │  告警分级     │    │  API + 认证      │
└─────────────┘    └──────────────┘    └──────────────────┘    └──────────────────┘
                          │                     │                      │
                          ▼                     ▼                      ▼
                   ┌──────────────┐    ┌──────────────┐      ┌──────────────┐
                   │  模型训练     │    │  日志持久化   │      │  Docker 部署  │
                   │  RF/XGB/LGBM │    │  JSON Lines  │      │  一键启动     │
                   │  算法对比     │    │  Rotating    │      │  健康检查     │
                   └──────────────┘    └──────────────┘      └──────────────┘
```

### 数据流

```
抓包 → 特征提取（流级/TCP/端口/时间/加密流量）
     → 双引擎检测（规则实时 + ML 周期聚合）
     → 告警分级（高危/中危/低危）
     → Web 面板实时展示 + 日志持久化
```

## 3. 命令行操作

所有命令通过入口脚本 `My_task.py` 执行：

```bash
python My_task.py <command> [args]
```

### 3.1 基础抓包 — capture

```bash
python My_task.py capture [秒数]
```

- **功能**：抓取网络流量，提取 8 个基础字段，保存到 `traffic_data.csv`
- **默认时长**：60 秒
- **输出字段**：`Src_IP, Dst_IP, Src_Port, Dst_Port, Protocol, Length, Timestamp, Label`
- **自动打标规则**：同一源 IP 出现次数 > 50 或访问不同目的端口数 > 20 → `Attack`，否则 → `Normal`

**示例**：

```bash
# 抓包 120 秒
python My_task.py capture 120
```

### 3.2 增强抓包 — ecapture

```bash
python My_task.py ecapture [秒数]
```

- **功能**：抓取网络流量，按流聚合提取 18 维增强特征，含 JA3 指纹和 TLS 分析
- **默认时长**：60 秒
- **特征构成**：基础（2 维）+ 流级（5 维）+ TCP 行为（5 维）+ 端口（1 维）+ 时间（2 维）+ 加密流量（3 维）

**示例**：

```bash
# 增强抓包 300 秒（5 分钟）
python My_task.py ecapture 300
```

### 3.3 模型训练 — train

```bash
python My_task.py train [--dataset NAME]
```

- **功能**：读取流量数据训练分类器，含算法对比和评估输出
- **支持算法**：RandomForest（默认）、XGBoost、LightGBM、MLP、LogisticRegression
- **类别均衡**：class_weight（默认）/ SMOTE / undersample
- **输出**：
  - `model.pkl` — 训练好的模型文件
  - `confusion_matrix.png` — 混淆矩阵图片
  - `evaluation_report.txt` — 评估报告
  - `train_data.csv` / `test_data.csv` — 训练/测试集划分（真实数据集时自动生成）

**当前模型状态**：

| 指标 | Attack | Normal |
|------|--------|--------|
| Precision | 0.97 | 1.00 |
| Recall | 1.00 | 0.99 |
| **F1** | **0.9828** | 1.00 |
| **整体准确率** | | **0.99** |

> 当前模型使用 CICIDS2017 真实数据集训练（13 特征映射，640K 训练 / 160K 测试），
> Attack F1 从合成数据的 0.00 提升至 0.9828。

**数据集选项**：

| 选项 | 说明 |
|------|------|
| `--dataset cicids2017` | CICIDS2017 公开数据集 |
| `--dataset nsl_kdd` | NSL-KDD 公开数据集 |
| `--dataset synthetic` | 合成演示数据（无实际检测能力） |
| `--dataset /path/to/file.csv` | 自定义 CSV 文件 |
| 不指定 | 自动检测本地 `traffic_data.csv` |

**示例**：

```bash
# 使用本地抓包数据训练
python My_task.py train

# 使用 CICIDS2017 数据集训练
python My_task.py train --dataset cicids2017

# 使用自定义数据集
python My_task.py train --dataset /path/to/my_data.csv
```

### 3.4 入侵检测 — detect

```bash
python My_task.py detect
```

- **功能**：对 `traffic_data.csv` 执行入侵检测
- **优先级**：若 `model.pkl` 存在，使用 ML 模型预测；否则回退到规则检测演示
- **输出**：预测统计（各类别数量）

**示例**：

```bash
python My_task.py detect
# 输出：
# [*] 模型预测完成，共 1500 条流量：
#     Normal: 1200
#     Attack: 300
```

### 3.5 Web 监控面板 — app

```bash
python My_task.py app
```

- **功能**：启动 Flask Web 监控面板
- **默认地址**：http://localhost:5000
- **面板功能**详见 [第 4 章](#4-web-监控面板)

### 3.6 一键演示 — demo

```bash
python My_task.py demo [--duration N] [--no-attack] [--no-browser]
```

- **功能**：启动 Web 面板 + 自动注入模拟攻击流量
- **默认时长**：60 秒

| 参数 | 说明 |
|------|------|
| `--duration N` | 演示持续秒数（默认 60） |
| `--no-attack` | 仅启动面板，不注入攻击 |
| `--no-browser` | 不自动打开浏览器 |

**示例**：

```bash
# 演示 120 秒
python My_task.py demo --duration 120

# 仅启动面板
python My_task.py demo --no-attack
```

### 3.7 攻击模拟 — attack_sim

```bash
python My_task.py attack_sim <command> [options]
```

| 子命令 | 说明 | 关键参数 |
|--------|------|----------|
| `syn_flood` | SYN Flood 模拟 | `--count 500` |
| `port_scan` | 端口扫描模拟 | `--count 200` |
| `udp_flood` | UDP Flood 模拟 | `--count 1000` |
| `all` | 全类型攻击模拟 | `--duration 30` |
| `generate_pcap` | 生成演示 pcap 文件 | `--output demo.pcap` |

**示例**：

```bash
# SYN Flood 500 包
python My_task.py attack_sim syn_flood --count 500

# 端口扫描 200 包
python My_task.py attack_sim port_scan --count 200

# UDP Flood 1000 包
python My_task.py attack_sim udp_flood --count 1000

# 全类型攻击 30 秒
python My_task.py attack_sim all --duration 30

# 生成 pcap 文件
python My_task.py attack_sim generate_pcap --output demo_attacks.pcap
```

## 4. Web 监控面板

### 4.1 启动面板

```bash
python My_task.py app
```

访问 http://localhost:5000 即可打开监控面板。

### 4.2 面板页签

面板采用 6 页签布局，通过顶部标签切换：

#### 总览页签

| 组件 | 说明 |
|------|------|
| 实时指标卡（9 个） | QPS、连接数、端口数、来源 IP 数、SYN/UDP/DNS 包数、数据包总数、检测准确率 |
| QPS 趋势图 | 实时折线图，最近 30 个数据点，自动滚动 |
| 攻击类型饼图 | DDoS / 端口扫描 / SYN 洪水 / UDP 洪水 / SQL 注入 / XSS / 暴力破解 / 横向移动分布 |
| 安全警报日志 | 颜色分级：高危红 / 中危橙 / 低危黄，最近 50 条滚动列表 |

#### 加密流量页签

| 组件 | 说明 |
|------|------|
| TLS 流量统计 | TLS 版本分布（TLS 1.2/1.3 等）、总会话数 |
| JA3 指纹 | Top JA3 哈希列表、指纹频次分布 |
| 可疑 TLS 记录 | 异常 JA3 / 罕见加密套件 / 过时 TLS 版本告警 |
| SNI 分析 | Server Name Indication 提取结果 |

#### 双引擎页签

| 组件 | 说明 |
|------|------|
| ML 状态 | 模型加载状态、预测循环运行状态 |
| 预测结果 | 最近 ML 预测类别、置信度 |
| 规则告警 | 规则引擎实时检出告警列表 |
| ML 检出 | ML 引擎周期聚合检出统计 |
| 模型控制 | 加载/停止 ML 模型按钮 |

#### 告警页签

| 组件 | 说明 |
|------|------|
| 级别过滤 | 全部 / 高危 / 中危 / 低危 四级筛选 |
| 告警列表 | 时间、类型、来源 IP、描述、级别，按时间倒序 |
| 统计摘要 | 各级别告警计数 |

#### 载荷检测页签

| 组件 | 说明 |
|------|------|
| 载荷输入 | textarea 输入待检测的 HTTP 载荷文本 |
| 示例按钮 | SQL 注入示例 / XSS 示例 / 正常请求示例 一键填充 |
| 检测结果 | 显示检测类型（SQL 注入 / XSS / 正常）及匹配模式 |

#### 控制页签

| 组件 | 说明 |
|------|------|
| 阈值配置 | DDoS / 端口扫描 / SYN 洪水 / UDP 洪水 四个阈值输入框，实时生效 |
| 抓包控制 | 开始抓包 / 停止抓包 按钮，抓包状态指示 |
| 数据保存 | 保存流量统计到 CSV 按钮 |

### 4.3 双引擎检测

Web 面板默认启用双引擎检测：

| 检测引擎 | 触发条件 | 告警等级 |
|----------|----------|----------|
| 规则 + ML 同时触发 | 双引擎确认异常 | **高危** |
| 仅 ML 触发 | 可能是未知攻击模式 | **中危** |
| 仅规则触发 | 可能是已知攻击模式 | **低危** |

### 4.4 实时抓包

1. 点击面板上的 **"开始抓包"** 按钮
2. 系统启动后台抓包线程，流量数据切换为真实抓包
3. 点击 **"停止抓包"** 结束抓包，回退到模拟数据模式

> **注意**：真实抓包需要安装 Npcap（Windows）或 root 权限（Linux）。

## 5. API 接口参考

### 5.1 接口列表

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/traffic` | 获取实时流量指标 |
| GET | `/api/alerts` | 获取最近 20 条警报 |
| GET | `/api/config` | 获取当前检测阈值配置 |
| POST | `/api/config` | 更新检测阈值 |
| GET | `/api/save` | 保存流量统计到 `traffic_stats.csv` |
| POST | `/api/capture/start` | 启动后台抓包线程 |
| POST | `/api/capture/stop` | 停止后台抓包线程 |
| GET | `/api/capture/status` | 查询抓包线程运行状态 |
| GET | `/api/tls/stats` | 获取 TLS 加密流量统计（版本分布、JA3 等） |
| GET | `/api/tls/suspicious?limit=50` | 获取可疑 TLS 记录 |
| GET | `/api/dual/stats` | 获取双引擎检测统计与攻击类型分布 |
| POST | `/api/dual/load` | 加载 ML 模型（JSON: `model_path`）并启动 ML 预测循环 |
| POST | `/api/dual/stop` | 停止 ML 预测循环 |
| POST | `/api/payload/check` | 应用层载荷检测（JSON: `payload`，识别 SQL 注入 / XSS） |

### 5.2 接口详情

#### GET /api/traffic

获取实时流量指标，每次调用触发一次数据更新。

```json
{
  "qps": 350,
  "connections": 120,
  "unique_ports": 45,
  "unique_ips": 30,
  "syn_count": 80,
  "udp_count": 150,
  "dns_count": 25,
  "packets": 3500,
  "timestamp": "2024-01-15T10:30:00"
}
```

#### GET /api/alerts

获取最近 20 条安全警报。

```json
[
  {
    "type": "DDoS",
    "level": "high",
    "src_ip": "10.0.0.100",
    "description": "QPS 650 超过阈值 500",
    "timestamp": "2024-01-15T10:30:00"
  }
]
```

#### POST /api/config

更新检测阈值（JSON 格式）。

```bash
curl -X POST http://localhost:5000/api/config \
  -H "Content-Type: application/json" \
  -d '{"ddos_threshold": 300, "port_scan_threshold": 30}'
```

#### GET /api/capture/status

查询抓包状态。

```json
{
  "running": true,
  "packet_count": 1500
}
```

### 5.3 API 认证

默认关闭。通过环境变量启用：

```bash
# 启用认证
export CAMPUS_IDS_AUTH_ENABLED=1
export CAMPUS_IDS_API_TOKEN=your-secret-token

# 请求时携带 token
curl -H "Authorization: Bearer your-secret-token" http://localhost:5000/api/traffic

# 或通过 query 参数
curl "http://localhost:5000/api/traffic?token=your-secret-token"
```

> HTML 页面免认证，仅 API 接口需要认证。

## 7. Docker 部署

### 7.1 一键启动

```bash
# 构建并启动（模拟模式，无需 Npcap）
docker compose up --build

# 后台运行
docker compose up --build -d

# 访问面板
# http://localhost:5000
```

### 7.2 环境变量配置

在 `docker-compose.yml` 或 `.env` 文件中配置：

```yaml
environment:
  - CAMPUS_IDS_DEMO_MODE=1          # Docker 中必须启用模拟模式
  - CAMPUS_IDS_AUTH_ENABLED=0       # API 认证（默认关闭）
  - CAMPUS_IDS_API_TOKEN=your-token # API Token
  - CAMPUS_IDS_WEB_PORT=5000        # Web 端口
  - CAMPUS_IDS_DDoS_THRESHOLD=500   # DDoS 检测阈值
  - CAMPUS_IDS_DATA_DIR=/app/data   # 数据目录
  - CAMPUS_IDS_LOG_DIR=/app/logs    # 日志目录
```

### 7.3 数据持久化

Docker Compose 配置了两个数据卷：

| 卷名 | 容器路径 | 说明 |
|------|----------|------|
| `model-data` | `/app/data` | 模型文件持久化 |
| `log-data` | `/app/logs` | 日志文件持久化 |

### 7.4 健康检查

容器内置健康检查，每 30 秒探测一次 `/api/traffic` 端点：

```bash
# 查看容器健康状态
docker compose ps

# 查看容器日志
docker compose logs -f
```

### 7.5 常用操作


## 10. 常见问题与排障

### Q1: `ModuleNotFoundError: No module named 'campus_ids'`

**原因**：可编辑包未安装或 Python 解释器不一致。

**解决**：

```bash
# 确认使用正确的 Python
which python   # Linux/macOS
where python   # Windows

# 重新安装
pip install -e .
```

### Q2: 抓包报错 `Scapy error: Npcap not found`

**原因**：Windows 未安装 Npcap 驱动。

**解决**：
1. 下载安装 [Npcap](https://npcap.com/)
2. 安装时勾选 **Install Npcap in WinPcap API-compatible Mode**
3. 重启终端

### Q3: Docker 中抓包不工作

**原因**：Docker 容器无法直接访问宿主机网络接口。

**解决**：Docker 部署默认启用模拟模式（`CAMPUS_IDS_DEMO_MODE=1`），使用模拟数据。如需真实抓包，请在宿主机运行。

### Q4: 训练时报 `⚠️ 无足够真实数据`

**原因**：本地 `traffic_data.csv` 不存在或样本不足 100 条。

**解决**：

```bash
# 方式一：先抓包采集足够数据（建议 60 秒以上，训练优先用 ecapture 的 18 维特征）
python My_task.py ecapture 120

# 再训练
python My_task.py train
```

当前 `train_data.csv` / `test_data.csv` 已包含 CICIDS2017 数据（640K / 160K），直接训练即可：

```bash
python My_task.py train
```

> **当前模型已使用 CICIDS2017 训练完成**，Attack F1 = 0.9828。

### Q5: XGBoost / LightGBM 训练失败

**原因**：未安装对应包。

**解决**：

```bash
pip install xgboost lightgbm
```

### Q6: Web 面板无法访问

**排查步骤**：

1. 确认服务已启动：`python My_task.py app`
2. 检查端口是否被占用：`netstat -ano | findstr 5000`（Windows）
3. 尝试更换端口：`set CAMPUS_IDS_WEB_PORT=8080 && python My_task.py app`
4. 检查防火墙设置

### Q7: API 返回 401 Unauthorized

**原因**：启用了 API 认证但未携带 Token。

**解决**：

```bash
# 方式一：Header 认证
curl -H "Authorization: Bearer your-secret-token" http://localhost:5000/api/traffic

# 方式二：Query 参数认证
curl "http://localhost:5000/api/traffic?token=your-secret-token"

# 或关闭认证
set CAMPUS_IDS_AUTH_ENABLED=0
```

### Q8: 日志文件在哪里？

| 日志文件 | 路径 | 说明 |
|----------|------|------|
| 全量日志 | `logs/app.log` | 轮转 10MB × 5 份，DEBUG 级别 |
| 检测日志 | `logs/detections.jsonl` | JSON Lines 格式，WARNING 级别以上 |

可通过 `CAMPUS_IDS_LOG_DIR` 环境变量修改日志目录。

### Q9: 如何调整检测灵敏度？

通过环境变量或 Web 面板调整阈值：

```bash
# 降低 DDoS 阈值（更敏感）
set CAMPUS_IDS_DDoS_THRESHOLD=200

# 提高端口扫描阈值（更宽松）
set CAMPUS_IDS_PORT_SCAN_THRESHOLD=100
```

或在 Web 面板的 **阈值配置** 区域实时调整。
