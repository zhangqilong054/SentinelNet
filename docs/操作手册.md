## 1. 系统概述

SentinelNet 是基于 Python 的实时网络入侵检测平台，核心能力：

- **流量采集**：Scapy/Npcap 实时抓包，支持基础特征和 18 维增强特征提取
- **双引擎检测**：规则检测（实时）+ ML 检测（周期聚合），三级告警（高危/中危/低危）
- **模型训练**：RF/XGBoost/LightGBM/MLP/LR 五种算法，含交叉验证和算法对比
- **Web 监控**：Flask 实时仪表盘，含 QPS 趋势图、告警日志、攻击类型饼图
- **攻击模拟**：SYN Flood/端口扫描/UDP Flood 模拟，支持 pcap 文件生成

### 系统架构

```
┌─────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────────┐
│  流量采集    │───▶│  特征提取     │───▶│  双引擎检测   │───▶│  Web 监控面板     │
│  Scapy/Npcap│    │  18 维特征    │    │  规则 + ML    │    │  Flask 实时仪表盘 │
│  TLS 解析   │    │  JA3 指纹     │    │  告警分级     │    │  API + 认证      │
└─────────────┘    └──────────────┘    └──────────────────┘    └──────────────────┘
                          │                     │                      │
                          ▼                     ▼                      ▼
                   ┌──────────────┐    ┌──────────────┐      ┌──────────────┐
                   │  模型训练     │    │  日志持久化   │      │  Docker 部署  │
                   │  RF/XGB/LGBM │    │  JSON Lines  │      │  一键启动     │
                   │  算法对比     │    │  Rotating    │      │  健康检查     │
                   └──────────────┘    └──────────────┘      └──────────────┘
```

## 3. 命令行操作

所有命令通过 `python My_task.py <command> [args]` 执行。

### 3.1 基础抓包 — capture

```bash
python My_task.py capture [秒数]   # 默认 60 秒
```

提取 8 个基础字段保存到 `traffic_data.csv`，自动打标（同源 IP >50 次或访问 >20 端口 → Attack）。

### 3.2 增强抓包 — ecapture

```bash
python My_task.py ecapture [秒数]  # 默认 60 秒
```

按流聚合提取 18 维增强特征（含 JA3 指纹和 TLS 分析），训练优先使用此命令。

### 3.3 模型训练 — train

```bash
python My_task.py train [--dataset NAME] [--quick]
```

**核心机制**：
- **算法**：RF（默认）/ XGB / LGB / MLP / LR
- **类别均衡**：class_weight（默认）/ SMOTE / undersample
- **防泄漏**：先 80/20 分层划分 → 仅训练集做类别均衡 → scaler 仅 fit 训练集 → 统一 held-out 测试集
- **模型注册表**：每次训练自动保存到 `models/runs/{run_id}/`，不会覆盖历史模型
  - `best.json` / `latest.json` / `registry.json` — 注册表指针与索引
  - 每个 run 目录包含：`model.pkl`、`scaler.pkl`、`metrics.json`、`metadata.json`、`feature_list.json`、`label_mapping.json`、`confusion_matrix.png`
  - `model.pkl` — 同时保存到传统路径（向后兼容）
  - run_id 格式：`YYYYMMDD_HHMMSS_<6位随机>`

**训练模式**：

| 模式 | 训练模型 | 包含步骤 | 典型耗时 |
|------|----------|----------|----------|
| 完整模式（默认） | RF+LR+XGB+LGB+MLP | 12 步全流程 | CICIDS2017 DDoS ≈ 4 分钟 |
| 快速模式（`--quick`） | RF+LGB | 仅训练+保存 | CICIDS2017 DDoS ≈ 3 秒 |

**模型指标**（CICIDS2017 DDoS，完整模式）：

| 模型 | F1 | Attack F1 | FPR |
|------|-----|-----------|-----|
| RandomForest | 0.9998 | 0.9998 | 0.0003 |
| LightGBM | 0.9998 | 0.9998 | 0.0004 |
| MLP | 0.9986 | 0.9988 | 0.0012 |
| LogisticRegression | 0.9795 | 0.9823 | 0.0005 |
| RF_CV | 0.9998±0.0001 | — | ROC-AUC=1.0000 |
| DualFusion（规则+RF） | 0.9998 | — | — |

**跨数据集泛化**（以 DDoS 训练）：

| 测试数据集 | F1 | 测试数据集 | F1 |
|------------|-----|------------|-----|
| PortScan | 0.9845 | Thursday-WebAttacks | 0.9807 |
| Friday-Morning | 0.9986 | Tuesday | 0.9535 |
| Thursday-Infilteration | 0.9996 | Wednesday | 0.4964 |

**性能优化**：规则基线向量化(10x+) / 融合向量化(10x+) / MLP 早停(5x) / CV 精简(2.8x) → 端到端 81min→4min，快速模式 3sec

**数据集选项**：

| 选项 | 说明 |
|------|------|
| `--dataset cicids2017` | CICIDS2017 公开数据集 |
| `--dataset nsl_kdd` | NSL-KDD 公开数据集 |
| `--dataset synthetic` | 合成演示数据 |
| `--dataset /path/to/file.csv` | 自定义 CSV |
| 不指定 | 自动检测 `traffic_data.csv` |
| `--quick` | 快速模式：仅 RF+LGB，跳过 CV/融合/跨数据集 |

**示例**：

```bash
python My_task.py train                              # 本地数据训练
python My_task.py train --dataset cicids2017         # CICIDS2017 完整模式
python My_task.py train --dataset cicids2017 --quick # 快速模式（3 秒）
```

### 5.3 关键接口详情

#### POST /api/config

```bash
curl -X POST http://localhost:5000/api/config \
  -H "Content-Type: application/json" \
  -d '{"ddos_threshold": 300, "port_scan_threshold": 30}'
```

#### POST /api/dual/load

支持三种加载方式（优先级：run_id > which > model_path）：

| 参数 | 说明 |
|------|------|
| `run_id` | 指定版本化 run（如 `20260912_145657_bs1zry`） |
| `which` | 注册表指针：`best`（默认）或 `latest` |
| `model_path` | 传统 pkl 路径（向后兼容） |

```bash
# 加载 best 模型
curl -X POST http://localhost:5000/api/dual/load -H "Content-Type: application/json" -d '{}'

# 加载指定 run
curl -X POST http://localhost:5000/api/dual/load -H "Content-Type: application/json" -d '{"run_id": "20260912_145657_bs1zry"}'
```

#### SSE 实时推送

Server-Sent Events 端点用于替代轮询，实现实时数据推送：

```javascript
// 前端连接示例
const es = new EventSource('/api/stream/traffic');
es.addEventListener('traffic', (e) => {
  const data = JSON.parse(e.data);
  // 更新 QPS、连接数等指标
});
```

| 端点 | 事件类型 | 说明 |
|------|----------|------|
| `/api/stream/traffic` | `traffic` | 每 2 秒推送流量指标，30 秒心跳保活 |
| `/api/stream/alerts` | `alert` | 实时推送新告警，连接时推送最近 5 条 |

> SSE 连接失败时，前端自动回退到 REST 轮询模式。

#### GET /api/health

返回系统各组件健康状态：

```json
{
  "status": "healthy",
  "components": {
    "database": "ok",
    "capture_thread": "ok",
    "ml_model": "ok",
    "memory_mb": 85.2,
    "uptime_seconds": 3600
  }
}
```

#### POST /api/attack/start

启动攻击模拟，支持 5 种攻击类型：

| 参数 | 说明 |
|------|------|
| `type` | 攻击类型：`syn_flood`/`port_scan`/`udp_flood`/`brute_force`/`lateral`/`all` |
| `count` | 攻击包数量（syn_flood/port_scan/udp_flood/brute_force/lateral） |
| `duration` | 持续秒数（all 模式） |

```bash
curl -X POST http://localhost:5000/api/attack/start \
  -H "Content-Type: application/json" \
  -d '{"type": "syn_flood", "count": 500}'
```

#### POST /api/model/train

异步启动模型训练：

| 参数 | 说明 |
|------|------|
| `dataset` | 数据集：`cicids2017`/`nsl_kdd`/`synthetic`/自定义路径 |
| `quick` | 快速模式（仅 RF+LGB），默认 `false` |

```bash
curl -X POST http://localhost:5000/api/model/train \
  -H "Content-Type: application/json" \
  -d '{"dataset": "cicids2017", "quick": true}'
```

训练进度通过 `/api/model/train-status` 轮询查询。

#### POST /api/demo/start

一键演示模式，自动启动抓包 + ML 模型加载 + 攻击模拟：

```bash
curl -X POST http://localhost:5000/api/demo/start \
  -H "Content-Type: application/json" \
  -d '{"duration": 60}'
```

## 6. 配置参数

所有配置集中在 `src/campus_ids/config.py`，支持环境变量覆盖（前缀 `CAMPUS_IDS_`）。

### 6.1 检测阈值

| 配置项 | 默认值 | 环境变量 |
|--------|--------|----------|
| DDoS 阈值 | 500 QPS | `CAMPUS_IDS_DDoS_THRESHOLD` |
| 端口扫描阈值 | 50 端口 | `CAMPUS_IDS_PORT_SCAN_THRESHOLD` |
| SYN 洪水阈值 | 100 | `CAMPUS_IDS_SYN_FLOOD_THRESHOLD` |
| UDP 洪水阈值 | 200 | `CAMPUS_IDS_UDP_FLOOD_THRESHOLD` |
| 暴力破解阈值 | 10 次/60秒 | `CAMPUS_IDS_BF_THRESHOLD` |
| 横向移动阈值 | 5 连接 | `CAMPUS_IDS_LATERAL_THRESHOLD` |

### 6.2 Web 面板与 ML 配置

| 配置项 | 默认值 | 环境变量 |
|--------|--------|----------|
| Web 端口 | 5000 | `CAMPUS_IDS_WEB_PORT` |
| 面板刷新间隔 | 2000 ms | `CAMPUS_IDS_REFRESH_MS` |
| ML 检测间隔 | 5.0 秒 | `CAMPUS_IDS_ML_INTERVAL` |
| ML 流缓冲区 | 10000 | `CAMPUS_IDS_ML_FLOW_BUFFER` |
| 最小训练样本 | 100 | `CAMPUS_IDS_MIN_TRAIN_SAMPLES` |

### 6.3 路径配置

| 配置项 | 默认路径 |
|--------|----------|
| 数据目录 | 项目根目录（`CAMPUS_IDS_DATA_DIR`） |
| 日志目录 | `logs/`（`CAMPUS_IDS_LOG_DIR`） |
| 模型注册表 | `models/runs/` + `best.json` + `latest.json` + `registry.json` |
| 传统模型 | `{DATA_DIR}/model.pkl` |

### 6.4 其他配置

| 配置项 | 默认值 | 环境变量 |
|--------|--------|----------|
| 模拟模式 | 关闭 | `CAMPUS_IDS_DEMO_MODE=1` |
| API 认证 | 关闭 | `CAMPUS_IDS_AUTH_ENABLED=1` |
| API Token | `campus-ids-token-2024` | `CAMPUS_IDS_API_TOKEN` |

## 7. Docker 部署

```bash
docker compose up --build       # 构建并启动（模拟模式）
docker compose up --build -d    # 后台运行
# 访问 http://localhost:5000
```

**环境变量**（在 `docker-compose.yml` 或 `.env` 中配置）：

```yaml
environment:
  - CAMPUS_IDS_DEMO_MODE=1          # Docker 中必须启用
  - CAMPUS_IDS_AUTH_ENABLED=0
  - CAMPUS_IDS_API_TOKEN=your-token
  - CAMPUS_IDS_WEB_PORT=5000
  - CAMPUS_IDS_DDoS_THRESHOLD=500
```

**数据持久化**：`model-data` → `/app/data`，`log-data` → `/app/logs`

**健康检查**：每 30 秒探测 `/api/traffic`

## 10. 常见问题与排障

### Q1: `ModuleNotFoundError: No module named 'campus_ids'`

可编辑包未安装或 Python 解释器不一致。解决：`pip install -e .`，确认 Python 路径一致。

### Q2: 抓包报错 `Npcap not found`

Windows 未安装 Npcap。下载 [npcap.com](https://npcap.com/)，安装时勾选 **WinPcap API-compatible Mode**。

### Q3: Docker 中抓包不工作

Docker 容器无法访问宿主机网络接口，默认启用模拟模式。真实抓包请在宿主机运行。

### Q4: 训练时报 `⚠️ 无足够真实数据`

本地 `traffic_data.csv` 不存在或样本不足 100 条。先运行 `python My_task.py ecapture 120` 抓包，或直接用 CICIDS2017：`python My_task.py train --dataset cicids2017`。

### Q5: XGBoost / LightGBM 训练失败

未安装对应包：`pip install xgboost lightgbm`

### Q6: Web 面板无法访问

1. 确认服务已启动  2. 检查端口占用：`netstat -ano | findstr 5000`  3. 更换端口：`set CAMPUS_IDS_WEB_PORT=8080`
