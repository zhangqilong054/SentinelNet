## 2. 本轮唯一发现：`POST /login` 契约变更（已申报，非回归）

T2 探针首轮 38/1：`login_form: POST /login 期望 [400]，实测 405`。

**根因**：今天下午翻转 `CAMPUS_IDS_FRONTEND` 默认值 legacy→new（commit `38d547f`）后，SPA 模式**不挂载** `pages.router`——legacy 表单登录路由退场，登录改走 SPA 的 `POST /api/login`，`POST /login` 无路由 → 405。此前 39/0 是默认值翻转**前**录的结果；翻转后只跑了 pytest（测试被 conftest 钉在 legacy）与 e2e，恰好都覆盖不到这条——**契约回放门禁按设计抓到了这次变更**。

**处置**：`tests/contract/mapping.py` 的 `login_form` 期望值更新为 `[400, 405]` 并注明两种模式的语义依据（legacy=400 表单校验渲染 / SPA=405 无路由）。复跑回放 → 0 差异，探针 → 39/0。

**方法论备注**：这是「默认值翻转」类变更的第 3 个波及面（前两个：conftest 隔离、首启引导模板），全量 pytest 与 e2e 均天然免疫，只有以默认模式跑的探针/门禁能抓到。后续任何默认值变更，探针三件套必须重跑。
