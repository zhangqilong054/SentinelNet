## 二、任务清单

### P0 — 开箱可用（不做完不能交付）

#### U1 首次启动引导：消灭"secret_key 拒绝启动"
- **改动**：`web_new/app.py::run_app()`（或 `_assert_secret_key`）在检测到「非 DEBUG + 默认密钥 + 无 `.env`」时，不直接崩，而是**自动生成 `.env`**（写入随机 `SECRET_KEY = secrets.token_hex(32)`、保留注释模板），打印提示后正常启动。已有 `.env` 或显式设置过密钥时不覆盖。
- **验收判据**：备份 `.env` 后删除之 → `python main.py app` 退出码 0、自动生成 `.env` 且密钥非默认值 → `/api/health` 200；再跑一次**不得**重新生成（幂等）。
- **回归**：`tests/test_single_worker.py`、`test_settings.py` 全绿；新增启动引导测试 ≥2 例（生成 / 幂等）。

#### U2 管理员密码找回：消灭"登不进去"
- **改动**：
  1. 新增 CLI 子命令 `python main.py reset-password [--user admin]`：生成随机密码（或 `--password` 指定），bcrypt/scrypt 哈希后更新 `users` 表，**明文只在 stdout 打印一次**；
  2. 在 `run_app()` 首次启动（新建 `.env`）时检测 `users` 表为空或 admin 哈希缺失 → 自动创建 admin 并打印一次性随机密码。
- **验收判据**：隔离 data_dir 下执行 reset → 用新密码 `POST /api/login` 返回 200 + 会话 cookie；旧密码失效；`--password ""` / 空用户名被拒。
- **关联**：本机当前 admin 的密码已丢失（哈希验不过任何候选），**U2 落地后需执行一次重置并把新密码告知用户**。
