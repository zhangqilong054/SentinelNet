## 非阻断待人工确认项（4 项）

1. **observe 页「200 包/秒 vs 0 B 字节/秒」不一致**：有包速无字节速，疑 `bytes_per_sec` 字段映射未随 T3 修复轮的 `qps/connections` 适配对齐，或初始数据为 0 属正常空态。需在真实流量下人工观察。
2. **tasks 页标题「任务中心」文字颜色偏浅**（浅底白字观感，对比度低）。需确认是标题样式问题还是截图渲染。
3. **config 页底部「分析载荷」按钮疑似被 fullPage 截图截断**（页尾出现孤立蓝色圆角条）。需人工滚动页面确认完整渲染。
4. **阈值标签中英混排**（3 个英文 key + 5 个中文名）。功能无碍，属文案统一性优化项。
