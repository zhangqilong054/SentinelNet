# T3.10 人工核对清单

> Playwright 自动化（`frontend/e2e/smoke.spec.ts`，9 项：①②④⑤⑥⑦⑧⑨⑩，全过）通过后，以下项目仍需**人工在浏览器里核对**。
> 自动化已覆盖：五路由 200、SSE 连接、表单校验 Toast、载荷送检、多标签页 CSRF 并发、限流 429、无 CSRF 被拒、5 页面基线截图、**SSE 真断线重连（真杀后端进程→拉起→自动恢复，⑩）**。

## 运行方式

```bash
cd frontend
npm run e2e             # 全量 9 项（webServer 自动拉起真实 uvicorn:8898，FRONTEND=new）
npm run e2e:baseline    # 仅重建 5 张视觉基线截图（-g 过滤 + --update-snapshots）
```

## 人工核对项

| # | 项目 | 操作 | 通过标准 |
|---|------|------|----------|
| 1 | 视觉基线比对 | 打开 `frontend/e2e/baselines/`（或测试后 `test-results/`）的 5 张 `baseline-*.png`，与旧版页面逐屏对比 | 新信息架构 4 区 + 剧本页布局合理；无破图/样式错乱/空白卡片（T0.4 视觉基线在阶段 0 未落地，本轮截图即为首版基线） |
| 2 | 图表刷新手感 | 启动流量相关任务后观察 ObserveView ECharts | 数据追加平滑、双 Y 轴刻度自适应、无卡顿闪烁 |
| 3 | Toast 视觉 | 触发成功/失败/警告三种 ElMessage | 位置居中上方、自动消失约 3s、颜色语义正确 |
| 4 | 多标签页人工流 | 双标签页同时操作启停任务/阈值 | 无白屏、无未处理报错弹窗；一方 403 后自动恢复（对应风险 R4） |
| 5 | SSE 长时稳定性 | 页面挂 10 分钟+，期间重启后端 | 状态标签经「重连中」回到「已连接」，数据恢复刷新（自动化⑩已覆盖"杀进程→自动重连"，此项补长时观察） |
| 6 | 窗口缩放 | 1280 / 1440 / 1920 宽度拖拽 | 侧边栏、卡片、表格无重叠溢出 |
| 7 | 登录流（若启用认证） | 设 `CAMPUS_IDS_LOGIN_ENABLED=1` 后走登录/登出/改密 | 跳转正确、CSRF token 刷新、登出后回到登录页 |

## 已知边界

- 自动化用例在**隔离 data_dir** 下运行（不触真实库/模型产物）；
- 限流用例消费 payload/analyze 的 30/min 配额，跑完后该端点 1 分钟内不可再用（仅对当次 uvicorn 实例有效）；
- ⑨ 截图基线首跑用 `--update-snapshots` 生成；后续回归用 `npm run e2e`（差异 >2% 判失败）。
